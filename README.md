# KingOfTime Input Subitem Extension

効率的に補助項目を入力できるようにする拡張機能です

### 機能

以下の補助項目入力を効率化します

- 案件を登録すると専用のボタンが配置され、クリックするだけで案件を登録できます
- 打刻時間の情報から自動的にボタンが配置され、時間入力の面倒を省きます
