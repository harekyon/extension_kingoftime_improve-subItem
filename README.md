# KingOfTime Input Subitem Extension

効率的に補助項目を入力できるようにする拡張機能です

### 機能

以下の補助項目入力を効率化します

- 案件を登録すると、専用のボタンが配置されます
- 打刻時間の情報から自動的にボタンを生成し、配置します。
