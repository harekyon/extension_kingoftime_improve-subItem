# KingOfTime Input Subitem Extension

Kingoftime の入力を便利にする拡張機能です。

## 機能

### 月別データ

- 1日あたりの仕事時間を計算します
- 1ヶ月に働いた総労働時間（実行時間）を視覚化します
  
### 補助項目

-   案件を事前に登録すると専用のボタンが生成され、クリックするだけで案件登録できます
-   打刻時間の情報から自動的にボタンを生成し、時間入力の手間を省きます
